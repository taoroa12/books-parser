# 📚 Books Parser

Парсер книжного магазина books.toscrape.com. Собирает названия, цены и рейтинги книг и сохраняет в Excel.

## 📋 Что делает

- Парсит несколько страниц сайта
- Собирает название, цену и рейтинг каждой книги
- Сохраняет результат в файл books.xlsx

## 🛠 Технологии

- Python 3.11
- requests
- BeautifulSoup4
- openpyxl

## 🚀 Запуск

1. Установи зависимости:
   pip install requests beautifulsoup4 openpyxl
2. Запусти скрипт:
   python3 parser.py
3. Результат сохранится в books.xlsx
